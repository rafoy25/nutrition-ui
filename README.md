# Nutrition UI

UI design and front-end for a nutrition tracking app: daily calorie and macro targets, meal logging, and progress dashboards.

## Reference designs

The [`reference-image/`](reference-image/) folder holds the visual inspiration for the project:

| File | What it shows |
| --- | --- |
| `image.png` | Home screen with a nutrition score ring, coach card, calorie/protein/carbs/fat targets, and a timeline of logged meals |
| `dashboard.webp` | Examples from existing nutrition apps: macro rings, calories consumed vs. burned, a daily meal plan, and a "calories left" tracker |

These images are for internal reference only. They are screenshots of third-party apps and should not be shipped as project assets.

## Contributing

1. Clone the repo and create a branch for your work:
   ```sh
   git clone <repo-url>
   cd nutrition-ui
   git checkout -b feature/short-description
   ```
2. Commit your changes with a clear message.
3. Push your branch and open a pull request against `main`.
4. Get at least one review before merging.
